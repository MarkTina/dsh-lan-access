# 局域网访问 (LAN Access)

一个带**左侧栏入口**的 DSH 插件：把本机 dsh Web 界面分享给同一局域网内的其他设备。

## 功能

- **左侧栏入口**：侧栏多一个地球图标，点开就是「局域网访问」面板。
- **可配置端口**：默认 `3180`，在 profile 的 `cordis.patch.yml` 覆盖 `lan-access` 行的 `port` 即可。
- **自动 0.0.0.0**：插件自建的反向代理监听 `0.0.0.0:<端口>`，本机所有网卡都能被访问。
- **列出所有 IP**：面板实时列出本机全部非回环 IPv4（网卡名 + 地址）。
- **可访问链接**：每个 IP 生成一个带一次性登录 token 的链接，点击即可在手机/其他电脑上打开 dsh。

## 为什么要做转发，而不是直接把 dsh 绑定到 0.0.0.0

实测与上游实现都表明：

1. dsh 的 `webserver` 配置**只接受一个具体的本地地址，明确拒绝 `0.0.0.0`**（wildcard），硬写会导致每次启动配置校验失败、Web GUI 起不来。
2. 宿主的 Web 服务始终监听 `127.0.0.1:<随机端口>`，首个页面请求必须携带进程 token（裸访问返回 401）。

因此本插件不改动宿主监听，而是**额外起一个监听 `0.0.0.0:<端口>` 的 HTTP/WebSocket 反向代理**，把流量透传到本机 loopback，并保持客户端访问时的 Host authority，让会话 cookie 正确绑定。这样既能「所有网卡可访问」，又不会让宿主绑定失败、不影响桌面端正常使用。

## 配置

`cordis.patch.yml`（bundle 默认值）：

```yaml
- insert:
    - id: lan-access
      name: '@local/lan-access'
      config:
        enabled: true
        port: 3180
```

在 **profile** 的 `cordis.patch.yml` 里覆盖（整体替换 config）：

```yaml
- id: lan-access
  config:
    enabled: true
    port: 8088
```

`enabled: false` 可关闭代理（插件仍显示面板，只是不监听端口）。改完需**重启 dsh** 生效。

## 使用

1. 打开 dsh，点左侧栏地球图标进入「局域网访问」。
2. 面板会列出本机所有 IPv4 与对应链接。
3. 用手机/另一台电脑打开任一链接即可。

## 安全提示

- 链接中含**一次性登录 token**；能拿到链接的人即可打开并使用这个 dsh。
- 本机权限较高（可能为 `danger-full-access`），**请仅在可信局域网内开启**，不要在公共 Wi-Fi 或不可信网络暴露端口。
- Windows 防火墙可能拦截入站端口，若其他设备连不上，请在“允许应用通过防火墙”中放行对应端口，或临时关闭防火墙测试。

## 已知限制

- 端口被占用或地址变化时，只有本插件的代理失效，面板会显示错误，宿主本身不受影响。
- 不提供设备配对/撤销等高级能力（可搭配其他远程访问插件使用）。
